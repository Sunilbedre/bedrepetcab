# Workflow

| Command | What you see |
|---------|----------------|
| **`npm run dev`** | **Hostinger / live site** on http://localhost:3010 |
| `npm run edit` | Old `src/` only — **not** the live layout |

**You:** ask Cursor to change something → open **localhost:3010** in Cursor forwarded ports.

**Cursor:** updates files, runs **`npm run dev`**, you refresh the browser.
